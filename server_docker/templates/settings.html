Linux / Docker 安装

使用可选 worker 容器：先在部署服务器上进入 server_docker，再执行以下命令。安装程序会下载官方模型、单独构建 worker 并校验健康状态；确认后才启用主程序。

./scripts/setup_sensevoice_docker.sh --enable-app

不想立即重启应用？省略 --enable-app，先只安装并检查 worker。安装时需要网络、约 1GB 以上的空余磁盘和额外 CPU/内存。

macOS 已有 worker

继续使用现有 launchd worker，不需要重复安装；请勿同时开启 Docker worker 与 macOS worker，否则会争抢同一队列。按现有部署说明配置模型后再启用主程序。

出于安全考虑，网页无权限运行 Docker、下载模型或安装系统软件。具体说明见项目文档 docs/SENSEVOICE-SETUP.md。
